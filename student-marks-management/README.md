# Student Marks Management System

## About
A C programming project that calculates a student's total marks, average marks, and grade for five subjects.

## Features
- Accepts marks for five subjects
- Validates marks from 0 to 100
- Calculates total and average marks
- Assigns a grade based on the average

## Technologies Used
- C Programming
- Arrays
- Loops
- Conditional Statements

## How to Run
Compile the C file using a C compiler such as GCC.

```bash
gcc student_marks.c -o student_marks
```

Run the program and enter the marks when prompted.

## Learning Outcomes
Practiced arrays, loops, input validation, arithmetic operations, and conditional logic.
